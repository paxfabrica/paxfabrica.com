Système Agentique Autonome Tier-1

Agent de Support Client Autonome (ReAct FSM & MCP Runtime)

Système agentique de niveau production automatisant le support client de premier niveau. Boucle d'exécution ReAct FSM à plafond strict (Nmax=3), calcul déterministe des délais statutaires de rétractation (14 jours) et compensations de retard, confinement PII défensif contre les injections de prompt indirectes, outils MCP typés et persistance multi-tenant.

Garde-Fous & Ingénierie Agentique

Les 6 Piliers de l'Automatisation Support Autonome

Allier la flexibilité du raisonnement LLM à la rigueur absolue du droit et de la sécurité d'entreprise

🔄

1. Boucle ReAct FSM avec Plafond Strict (N ≤ 3)

Machine à états finis alternant Pensée (Thought), Action et Observation. Un plafond absolu de 3 itérations interdit tout emballement récursif ou boucle infinie, déclenchant une escalade humaine automatique en cas de doute.

⚖️

2. Règles Métier Statutaires Déterministes

Le calcul du délai de rétractation de 14 jours (Code de la consommation art. L221-18) et des compensations de retard express est opéré en Python pur. Aucun calcul juridique critique n'est délégué à l'approximation du LLM.

🛡️

3. Encapsulation XML Défensive & Isolation PII

Tous les e-mails non fiables sont encapsulés dans des balises <user_email> neutralisant les attaques par injection de prompt indirecte. Les accès ERP sont vérifiés contre l'adresse e-mail authentifiée de l'expéditeur.

🔌

4. Runtime d'Outils Découplé (Protocole MCP)

Outils typés Pydantic V2 conformes au standard Model Context Protocol (MCP). Un bouclier d'exceptions étanche isole les pannes d'API externes pour maintenir la stabilité de la session.

⚡

5. Cache d'Idempotence SHA-256 (Redis)

Déduplication stricte des opérations critiques via une clé SHA256(session:outil:arguments) avec un TTL de 15 minutes, garantissant qu'aucun remboursement ou bon d'achat ne puisse être généré deux fois.

💻

6. Double Ingress : API REST & CLI Rich

API FastAPI asynchrone pour l'intégration continue de webhooks e-mails et interface CLI interactive développée avec Typer et Rich pour l'administration et les diagnostics opérationnels.
